# 플레이 스토어 등록정보 (OPS-08)

플레이 콘솔 → 앱 → 성장 → 스토어 등록정보 → 기본 스토어 등록정보에 그대로 붙여 넣는다. 기본 언어는 한국어(ko-KR).
글자 수는 플레이 한도 안이다(앱 이름 30자, 간단한 설명 80자, 자세한 설명 4000자). 문구를 고치면 화면 문구 규칙(CLAUDE.md '화면 문구')을 따른다.

## 앱 이름 (30자)

```
봐드림 - 영상으로 보는 원격 A/S
```

## 간단한 설명 (80자)

```
링크 하나 보내면 고객님 폰 카메라로 고장 난 곳을 같이 보고 짚어 드려요.
```

## 자세한 설명 (4000자)

```
출장 가기 전에 먼저 봐 드리세요.

봐드림은 A/S 기사님과 고객님을 영상으로 이어 주는 앱이에요. 기사님이 링크를 보내면 고객님은 링크를 누르고 카메라를 켜기만 하면 돼요. 고객님은 앱을 깔거나 가입하지 않아도 돼요.

■ 이렇게 써요
1. 앱에서 '새 A/S 시작'을 누르면 고객님께 보낼 링크가 나와요.
2. 카카오톡이나 문자로 링크를 보내요.
3. 고객님이 링크를 열고 '카메라 켜고 시작하기'를 누르면 바로 연결돼요.
4. 고객님 폰 화면을 보면서 어디를 만져야 하는지 짚어 드려요.

■ 말로 설명하기 어려운 걸 화면으로 보여 줘요
• 가리키기: 기사님이 영상을 톡 누르면 고객님 화면에 빨간 표시가 떠요. "그 버튼 말고 오른쪽 거요"를 말로 안 해도 돼요.
• 멈추고 그리기: 화면을 멈춘 뒤 손가락으로 동그라미나 화살표를 그려 보여 드려요.
• 방향 알려 주기: 위·아래·왼쪽·오른쪽, 가까이·멀리를 누르면 고객님 화면에 노란 화살표가 떠요. 카메라를 어디로 돌려야 하는지 바로 알아요.
• 물체에 붙는 표시: 길게 누르면 그 자리에 핀이 꽂혀요. 고객님이 폰을 움직여도 핀이 그 물건을 따라가요.
• 카메라·손전등: 기사님이 고객님 폰의 앞뒤 카메라를 바꾸고, 손전등이 있는 폰이면 손전등도 켤 수 있어요. 어두운 기계 안쪽도 비춰 볼 수 있어요.
• 사진 찍기: 고객님 폰 카메라로 바로 찍어서 기사님 폰에 받아요. 부품 번호나 오류 표시를 남겨 둘 때 좋아요.

■ 고객님은 앱이 필요 없어요
링크는 크롬, 사파리, 삼성 인터넷에서 그대로 열려요. 카카오톡 안에서 열면 인터넷 앱으로 넘어가는 방법을 크게 안내해 드려요. 글씨와 버튼을 크게 만들어서 연세 있는 사장님도 쉽게 따라 하세요.

■ 잘 끊기지 않게 만들었어요
두 폰이 바로 이어지지 않는 망(회사 와이파이, 일부 통신사)에서도 중계 서버를 거쳐 연결돼요. 잠깐 끊겨도 다시 연결해 드려요.

■ 영상은 저장하지 않아요
영상과 목소리는 두 폰이 직접 주고받고 서버에 남기지 않아요. 통화 중에 찍은 사진도 서버에 올리지 않고 기사님 폰에만 저장돼요. 고객님 이름과 전화번호는 받지 않아요.

■ 이런 분께 맞아요
• 카드 단말기, 포스, 프린터처럼 현장에 있는 기계를 관리하는 기사님
• 보일러, 에어컨, 정수기, 가전 설치·수리 업체
• 전화로 설명하다 결국 출장을 가게 되는 일이 잦은 분

■ 시작하기
카카오 계정으로 바로 가입해요. 가입하면 한 달에 30건까지 상담을 만들 수 있어요.

문의: contact@bwadrim.com
개인정보 처리방침: https://bwadrim.com/privacy
```

## 새로운 기능 (출시 노트, 500자)

```
봐드림 첫 버전이에요. 링크를 보내 고객님 폰 카메라로 고장 난 곳을 보고, 가리키기·그리기·방향 알려 주기·사진 찍기로 짚어 드려요.
```

## 연락처·분류

- 앱 분류: **앱** → 카테고리 **비즈니스**
- 태그(선택): 비즈니스 커뮤니케이션, 생산성
- 이메일: `contact@bwadrim.com` (스토어에 공개된다)
- 웹사이트: `https://bwadrim.com`
- 전화: 선택. 넣으면 공개된다
- 개인정보처리방침 URL: `https://bwadrim.com/privacy` (앱 콘텐츠 → 개인정보처리방침에도 같은 주소)
